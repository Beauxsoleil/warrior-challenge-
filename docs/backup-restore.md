# M1 private outbox export

Export private outbox JSON downloads schemaVersion, export time, limitation and
all entries for the current competition/actor on this browser, preserving IDs,
payloads, transport states and errors. It does not export SDK caches/tokens.
Keep it private. Synced records remain in the file to explain dependency history.
Other accounts/devices' captures are not included. A download is not proof of a
second safe copy: open/check it and copy to another owned drive/device.

This is NOT yet the lossless whole-competition export/restore system. M5 must
add versioned config/roster/policy, accepted journal with timestamp precision,
control/publication provenance, manifest counts/fingerprints, safe CSV and print
forms, validation preview and separate practice restore with tally comparison.
Never impersonate original actors or fabricate original receivedAt on import.
No restore button or backend import is implemented in M1.
