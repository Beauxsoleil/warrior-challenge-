# Practice runbook

Use README local setup. All accounts/teams are synthetic. Prepare two browser
profiles (not merely two tabs) for independent scorers and a third for admin.
Sign in and load assignment/roster while online. Confirm local database ready.
Capture while uploader paused or network unavailable; expect locally pending.
Reconnect both; same-team submissions must produce CONFLICT. Admin chooses a
complete value and reason; both histories remain. Test own undo then replacement.

On local failure: stop relying on app, write bib/value/order on paper, tell the
official. On sync rejection: retain ID/payload, export private outbox, review with
admin. Never clear browser storage or change IDs/authors to force acceptance.
Do not sign out expecting unsynced data to appear on another device.

M1 cannot run an official competition. Event-day preparation, station
reconciliation, distinct-official reopening, finalization, independent tally,
backup finish recording and official sign-off remain M2-M6 work. No deployment
is authorized by this repository. No automatic upgrade/service worker exists.
